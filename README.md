# 🤖 AI Mock Interview System

An AI-powered interview preparation and candidate evaluation platform built using Python and Streamlit.

The system analyzes resumes, evaluates interview answers, generates performance reports, and ranks candidates based on Resume ATS Score and Interview Performance.

## ✨ Features

### 📄 Resume Analysis
- Resume PDF Upload
- Candidate Information Extraction
- Technical Skill Detection
- ATS Resume Score Calculation
- Job Description Matching
- Missing Skills Detection
- AI Resume Suggestions

### 🎤 AI Mock Interview
- Role-Based Interview Questions
- Data Scientist Interview
- ML Engineer Interview
- AI Engineer Interview
- Python Developer Interview
- AI Answer Evaluation
- Question-wise Scoring
- Overall Interview Score

### 📊 Analytics Dashboard
- Interview Performance Analysis
- Score Visualization
- Candidate Insights

### 🏆 Candidate Ranking System
- Resume Score + Interview Score Combination
- Automatic Candidate Ranking
- Top Candidate Identification

### 📑 PDF Report Generation
- Resume Analysis Report
- Interview Performance Report
- AI Recommendation
